# MyNegosyo
A Filipino small-business mobile management app built with Expo / React Native.

## Run
1. Install Node.js and Expo tooling.
2. In this folder run `npm install`.
3. Run `npx expo start`.
4. Scan the QR code using Expo Go, or run Android/iOS/Web.

## Included modules
Dashboard, Inventory, Sales/POS, Services, Utang, GCash, E-Load, Bills, Employee Salary, Cash Vault, Reports, Barcode placeholder, Settings/Profile.

## Notes
This app uses local device storage for the demo. Replace the storage layer with your own API/database for production multi-device sync.

The UI is an original MyNegosyo implementation inspired by common small-business dashboard patterns and the referenced MyTindahan workflow; it does not use MyTindahan branding or proprietary assets.
